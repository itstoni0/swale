# Swale

Swale is a Go CLI.
Swale generates Terragrunt units and stacks that reference modules from a catalog.

## Build

Run `go build ./cmd/swale`.
The build writes `./swale`.

## Use

Run `swale --help`.
Run `swale init`.
Run `swale scaffold`.
`swale init` and `swale scaffold` are stubs for now.
